# 75 Hard

A daily tracker for the 75 Hard challenge (plus a Bible chapter a day) that you can add to your phone's home screen.

- Two workouts, water, 10 pages of reading, a Bible chapter, diet and a progress photo each day
- 75-day calendar, totals, and a warning when a day is missed
- Progress photos with a first-vs-latest comparison
- Works offline; everything is saved on your device. Use **Settings → Save backup** now and then.

Hosted with GitHub Pages. Open the site on your phone, then:
- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Add to Home screen / Install app
